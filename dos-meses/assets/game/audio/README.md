# Fuente del ladrido de Mía

`mia-dachshund-bark.wav` contiene dos ladridos breves extraídos de
“Miniature Dachshund Bark - Indoors.wav”, grabado por Ligidium y publicado
con licencia CC0 en Freesound:

https://freesound.org/people/Ligidium/sounds/192236/

El fragmento se normalizó y se recortó a 1,05 segundos para su uso como
efecto al recoger el objeto especial de Mía.
